How taste works
  1. 1
    Extract from a project or folder
    A model reads a finished model, board, firmware or a whole folder - source, checks and drawn notes - and proposes statements.
  2. 2
    Review and save to a palette
    Accept, edit or reject each proposal; only what you accept is kept. Statements can also be written by hand.
  3. 3
    Attach it, or @-mention it in Chat
    Every agent on an attached project gets it: MUST always, PREFER unless the note says otherwise, AVOID never.
